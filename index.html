Generate a trending repo idea — everything in one package

Like GitNym generates a name, this generates a whole repo idea: name, pitch, README outline, features, 72-hour MVP, evidence, competitors, and exports — in one package. Type what you want to build, and the generator builds it from the strongest matching snapshot evidence. Only the evidence numbers are data. The name, pitch, features, and stack are SUGGESTIONS. If nothing in the snapshot matches, it does not call the idea “trending” — it shows the closest snapshot signals instead, labelled closest-match.

Generate new ideas

Like GitNym generates names, this generates new idea cards — but only from snapshot evidence. Type a topic or keyword (optional) to pick which snapshot signals to build from, then Generate. “Generate more variants” makes new names and pitches from the same evidence — the evidence numbers do not change, because no new data was collected. A seed with no matching signal gets no invented card: you get the closest snapshot signals instead, labelled as closest-match, not as evidence for your seed.

Idea cards

Interest signal formula (published, ESTIMATE — not a virality prediction): 50 × (avg stars/day ÷ max avg stars/day in snapshot) + 30 × (sample stars ÷ max sample stars) + 20 × (min(HN + dev.to title mentions, 5) ÷ 5), rounded to 0–100. Components are shown on each card.

What this evidence is — and is not

  • Is: a dated sample (first 30 GitHub Search results for repos created after 2026-10-17, sorted by stars), plus 10 HN Algolia stories and 10 dev.to articles from the same build.
  • Is not: an official trending feed, a complete market survey, or proof that a gap exists. Competitor rows are the top matches in this snapshot sample, not a global top 3.
  • Names on cards are suggestions only. Their npm / PyPI / domain availability was not checked here.
