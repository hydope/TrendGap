What repo should you build next?

Live recently-created repos, most-starred first — with a specific spin-off idea for each one, not a template.

This is NOT an official trending feed — GitHub has no official trending API. “Trending now” here means: repos created in the last 7 days, sorted by stars in GitHub Search, fetched live from your browser with no key. Ideas are SUGGESTIONS. Only the evidence numbers are data. Angles and gaps are hypotheses, never proven gaps. No virality prediction, no fake trending claim.

Search runs a live GitHub Search for your keywords in repo names and descriptions, all-time (not just the last 7 days — niche topics like Ray-Ban Meta have almost nothing new in 7 days), ranked by relevance (name match > description match > topic match), then stars. If your exact words match nothing, it tries shorter versions and tells you which words it dropped. If nothing matches at all, the page says so plainly, shows trending repos only as unrelated exploration, and generates no package from them.

Interest signal formula (ESTIMATE, relative to the fetched set, not to all of GitHub): 50 × (stars/day ÷ max stars/day in fetched set) + 50 × (stars ÷ max stars in fetched set), rounded 0–100, components shown on each package.

What this evidence is — and is not

  • Is: GitHub Search results for repos created in the last 7 days, sorted by stars, fetched live from your browser (no key, cached 1 hour), or — only if live search fails — the dated snapshot in data/snapshot.json, clearly labelled as a fallback with its date.
  • Is not: an official trending feed, a complete market survey, or proof that a gap exists. Competitors are other repos in the fetched set with the same language or a shared topic, not a global top 3.
  • Angles are hypotheses based only on the source repo's listed topics and language. A missing topic is not proof the repo lacks a feature — topics are not a feature list.
  • Names on ideas are suggestions only. Their npm / PyPI / domain availability was not checked here.
  • Rate limits: unauthenticated GitHub Search is limited (about 10 searches/minute per IP in practice). If you hit it, the page says “rate-limited” and falls back to the snapshot — it never invents repos.
